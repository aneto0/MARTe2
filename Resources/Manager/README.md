# marte2-manager

`marte2-manager` is a lightweight CLI tool designed to simplify the development workflow.

## Overview

This tool helps streamline common tasks when working with MARTe2 by:

- Providing quick project scaffolding
- Simplifying the addition of new components (e.g. GAMs)
- Assisting with project structure and deployment setup

## Features

- 🚀 Create new MARTe2 project skeletons
- 🧩 Generate boilerplate code for new components
- 🛠️ Standardize project layout and structure
- ⚡ Reduce repetitive setup work
